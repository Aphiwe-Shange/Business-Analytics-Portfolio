# University Registration Process Improvement 

## Business Problem 

A university's registration process experiences delays due to manual reviews, duplicated activities and inefficient communication between departments.

## Objective

Analyse the current registration process, identify inefficiencies and propose improvement that reduce turnaround time and improve the student  experience. 

# Skills Demonstrated

- Business Analysis 
- Process Mapping
- Requirements Gathering 
- Problem Solving 
- Stakeholder Analysis
- Process Improvement
