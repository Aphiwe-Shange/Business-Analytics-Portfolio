# Sales Performance Dashboard
 
## Business Problem
 
A retail company requires visibility into sales performance, profitability, product performance and regional trends to support strategic decision-making.
 
## Objective
 
Develop an interactive Power BI dashboard that provides management with key performance indicators and actionable business insights.
 
## Dataset
 
Sample Superstore Dataset
 
## Tools Used
 
- Power BI Desktop
- Microsoft Excel
 
## Key Metrics
 
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Profit Margin %
 
## Key Findings
 
- West region generated the highest sales and profit.
- South region generated the lowest sales.
- Technology was the most profitable category.
- Phones and Chairs generated the highest sales.
- Sales increased significantly between 2015 and 2017.
 
## Recommendations
 
- Increase investment in high-performing regions.
- Investigate underperforming regions.
- Focus inventory and marketing efforts on profitable products.
- Review lower-performing categories to improve profitability.
